# MediCare Hospital Management System

## 📌 Project Description

The Hospital Management System is an Object-Oriented Programming (OOP) project developed in Python.

The system is designed to manage hospital information including patients, staff, departments, and hospital operations.

## 🎯 Project Objectives

- Apply Object-Oriented Programming concepts.
- Organize the hospital system into separate classes.
- Manage patients and staff within departments.
- Store and display basic information about hospital members.
- Provide a simple user interface to interact with the system.

## 🏗️ Project Structure

The project is divided into several Python files:

- `person.py` - Contains the base `Person` class.
- `patient.py` - Contains the `Patient` class inherited from `Person`.
- `staff.py` - Contains the `Staff` class inherited from `Person`.
- `department.py` - Manages departments, patients, and staff.
- `hospital.py` - Manages hospital information and departments.
- `main.py` - Runs the system and provides the user interface.

## 🧩 OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Methods
- Constructors
- Code Organization
